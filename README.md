# Wired ANC Studio

Android Studio source project for a wired-headset ANC audio-processing prototype. Download the project archive from `WiredANCStudio.zip`, extract it, and open the `WiredANCStudio` folder in Android Studio.

**Note:** This is an Android app source repository, not a GitHub Pages website. The audio algorithm is a prototype and has not been validated as effective noise cancellation. Do not rely on it for hearing protection.
