# Wired ANC Studio

Android Studio project source for the Wired ANC Studio prototype.

- [Download the complete Android Studio project ZIP](./WiredANCStudio.zip)
- Extract the ZIP and open the `WiredANCStudio` folder in Android Studio.
- Allow Gradle to sync dependencies, then build and run on a supported Android device.

**Important:** This is an Android application source project, not a GitHub Pages website. The current audio-processing implementation is a prototype and has not been validated as effective active noise cancellation. Do not rely on it for hearing protection.
